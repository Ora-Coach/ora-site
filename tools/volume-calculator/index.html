How the sets are counted

  • Hard sets only. Count working sets taken within about 3 reps of failure (RPE 7 or higher). Warm-ups don't count.
  • Full set for the main muscle, half for helpers. A set of bench press is 1 set for chest and ½ for triceps and shoulders. A set of curls is 1 for biceps. This is a common rule of thumb, not an exact measure.
  • Per week, not per workout. Add up every session. Squatting 3 sets on Monday and 3 on Thursday is 6 sets a week.

How much volume do you need?

Research on muscle growth finds more weekly sets tend to build more muscle, up to a point. A 2017 meta-analysis found that 10 or more sets per muscle per week led to more growth than fewer sets. Many lifters do well between 10 and 20.

  • Beginners grow on less. 6-10 hard sets per muscle is plenty while every week brings new strength.
  • Stalling with good sleep and food? Add a few sets to the muscles that lag, a couple at a time.
  • Above 20 can work for some muscles and some people, but it's easy to dig a recovery hole. Watch whether your lifts still go up.

Questions

How many sets per muscle per week should I do?

Most research on muscle growth finds that about 10 or more hard sets per muscle per week tends to beat fewer, and many lifters grow well in the 10-20 range. Beginners can grow on less. More than 20 can work, but only if you recover from it.

What counts as a hard set?

A working set taken close to failure, usually within about 3 reps of it (RPE 7 or higher). Warm-up sets and easy sets don't count.

Do compound lifts count for the smaller muscles?

Partly. A common rule of thumb counts a set as a full set for the main muscle and half a set for muscles that help, like the triceps in a bench press. That's what this calculator does.

Is it better to split a muscle's sets across the week?

Spreading them over two or more sessions makes each session more manageable and keeps the sets higher quality. Research suggests weekly volume matters more than how often you train a muscle, as long as the sets are hard.

What if a muscle is way above 20 sets?

That's a lot of work for one muscle. If you're recovering well and still progressing, it may be fine. If the lifts stall or joints ache, move some of those sets to muscles that are lower.
